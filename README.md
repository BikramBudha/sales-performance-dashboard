# Sales Performance Dashboard

## Project Overview
This project analyzes sales performance using Excel. The goal is to turn raw sales data into clear business insights using KPIs, pivot tables, and dashboard visuals.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Visualization
- Business Analytics

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin

## Dashboard Features
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top Sub-Categories by Sales
- Profit by Category

## Key Insights
- Sales performance changes across months.
- Some categories generate higher revenue than others.
- Regional sales performance is different.
- High sales do not always mean high profit.
- The dashboard helps identify business opportunities.
